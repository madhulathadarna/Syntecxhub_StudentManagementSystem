# Student Management System

## Project Description

The Student Management System is a console-based Java application developed to manage student records efficiently. This project allows users to add, view, search, and update student details using a menu-driven program.

The system supports student IDs with:
- Numbers
- Alphabets
- Alphanumeric combinations

It also calculates total marks, percentage, and grades automatically based on subject marks.

The project is developed using Java programming concepts such as classes, objects, ArrayList, methods, loops, and exception handling.

---

## Features

- Add Student Details
- View All Students
- Search Student Profile
- Update Student Details
- Support Alphanumeric Student IDs
- Subject-wise Marks Entry
- Automatic Total Calculation
- Automatic Percentage Calculation
- Automatic Grade Generation
- Exception Handling
- Menu-Driven Program
- Formatted Console Output
